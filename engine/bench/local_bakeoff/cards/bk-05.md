# Set production log level and add export settings

## Context

`config/tally.ini` still ships with debug logging, and the new CSV export needs its own settings section before it can be switched on.

## Scope

- In `config/tally.ini`, change `log_level = DEBUG` to `log_level = WARNING`.
- Append a new `[export]` section at the end of the file with exactly two keys, in this order: `format = csv` then `include_header = true`.
- Leave every other section and key as it is.

## Out of scope

- Any Python code that reads the config.
- Renaming or reordering existing keys.

## Acceptance criteria

Every item below must pass. Shell items run from the repository root.

```yaml
acceptance_criteria:
  - description: "log level is WARNING"
    type: file_contains
    path: "config/tally.ini"
    pattern: '^log_level = WARNING\s*$'
    regex: true
  - description: "debug logging is gone"
    type: file_lacks
    path: "config/tally.ini"
    pattern: 'log_level = DEBUG'
  - description: "export section is last and complete"
    type: file_contains
    path: "config/tally.ini"
    pattern: '\[export\]\r?\nformat = csv\r?\ninclude_header = true\s*\Z'
    regex: true
  - description: "currency is unchanged"
    type: file_contains
    path: "config/tally.ini"
    pattern: '\[tally\]\r?\ncurrency = USD\r?\ndecimal_places = 2\r?\n'
    regex: true
  - description: "report section is unchanged"
    type: file_contains
    path: "config/tally.ini"
    pattern: '\[report\]\r?\ncolumn_gap = 2\r?\n'
    regex: true
```
