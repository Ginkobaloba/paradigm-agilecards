# Add Inventory.low_stock for reorder alerts

## Context

The shop wants a reorder list: every SKU whose stock has fallen below a threshold, most urgent first.

## Scope

- Add `Inventory.low_stock(self, threshold: int) -> list[str]` in `tally/inventory.py`.
- Return the SKUs whose `qty` is strictly less than `threshold`.
- Order by `qty` ascending, then by SKU ascending to break ties.
- Raise `ValueError` if `threshold` is negative.
- The test is `tests/test_low_stock.py`.

## Out of scope

- Persisting alerts or printing them.
- Changing `add`, `restock` or `remove`.
