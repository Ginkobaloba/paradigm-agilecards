# Fix format_cents for negative amounts

## Context

Refund lines in the shop report print nonsense: `format_cents(-5)` returns `$-1.95` instead of `-$0.05`, because `divmod` floors toward negative infinity. Positive amounts are already correct.

## Scope

- In `tally/money.py`, fix `format_cents` so a negative amount renders as a leading `-` followed by the formatted absolute value, e.g. `-5 -> -$0.05`, `-123456789 -> -$1,234,567.89`.
- Keep the existing output for zero and positive amounts unchanged.
- The failing test is `tests/test_format_cents.py`.

## Out of scope

- `parse_amount` (another card owns it).
- Any change to the tests.
