# Add unit tests for weekend and negative date spans

## Context

`tally.dates` has thin coverage: nothing checks Sunday in `is_weekend`, and nothing checks that `days_between` is signed when the end date comes first. Add two tests before anyone refactors it.

## Scope

- In `tests/test_dates.py`, add `test_is_weekend_sunday`: Sunday 2026-11-01 is a weekend day and Monday 2026-11-02 is not.
- In the same file, add `test_days_between_negative`: from 2026-10-28 to 2026-10-01 is `-27`, and the same date to itself is `0`.
- Keep the three existing tests. All five must pass against the current `tally/dates.py`.

## Out of scope

- Changing `tally/dates.py` (the tests must pass as the code is today).
- Tests for other modules.
