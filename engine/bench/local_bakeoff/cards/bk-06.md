# Fix slugify leaving repeated and trailing hyphens

## Context

SKU slugs come out as `hello--world-` for `Hello, World!`. Every run of non-alphanumeric characters should become a single hyphen, and slugs should never start or end with one.

## Scope

- In `tally/text.py`, fix `slugify` so that each run of characters that are not ASCII letters or digits becomes one `-`.
- Strip leading and trailing hyphens. An input with no ASCII letters or digits gives `""`.
- Keep lowercasing as it is.
- The failing test is `tests/test_slugify.py`.

## Out of scope

- Unicode transliteration (non-ASCII letters stay separators).
- Changing `pad_right`.
