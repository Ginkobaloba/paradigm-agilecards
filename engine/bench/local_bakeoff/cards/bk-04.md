# Remove the deprecated tally.legacy module

## Context

`tally/legacy.py` only holds `old_format`, a deprecated alias for `format_cents` that has warned for two releases. Nothing in the package uses it, and the 0.4.0 release drops it.

## Scope

- Delete `tally/legacy.py`.
- In `tally/__init__.py`, remove the `from .legacy import old_format` import and the `"old_format"` entry in `__all__`.
- The test is `tests/test_legacy_removed.py`.

## Out of scope

- Changing `format_cents` itself.
- CHANGELOG or README edits (the release card does those).

Every item below must pass. Shell items run from the repository root.
