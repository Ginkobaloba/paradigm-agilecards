# Add text.truncate for report labels

## Context

Long product names overflow the report columns. We need a small helper that shortens a label to a fixed width and marks the cut with a suffix.

## Scope

- Add `truncate(text: str, width: int, suffix: str = "...") -> str` to `tally/text.py`.
- If `len(text) <= width`, return `text` unchanged.
- Otherwise return the first `width - len(suffix)` characters followed by `suffix`, so the result is exactly `width` characters long.
- If `width < len(suffix)`, raise `ValueError`.
- The test is `tests/test_truncate.py`.

## Out of scope

- Using `truncate` inside `tally/report.py` (a later card).
- Changing `slugify` or `pad_right`.
